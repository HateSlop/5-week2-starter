# 🇯🇵 일본어 학습 도우미

한국어 사용자를 위한 대화형 일본어 학습 AI 프로토타입입니다.

## 실행

```bash
cd HateSlop_week2
python projects/jaehakie/app.py
```

## 사용법

- 한국어 단어나 문장을 입력하면 자연스러운 일본어 표현을 알려줍니다.
- 일본어 단어나 문장을 입력하면 한국어로 설명해 줍니다.
- `오늘의 표현`을 입력하면 실용적인 일본어 회화 표현을 추천합니다.
- `quit` 또는 `exit`으로 종료합니다.

## 기술 스택

- Python + OpenAI Responses API (`gpt-4o-mini`)
