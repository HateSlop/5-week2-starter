# 스무고개 미니게임 AI

OpenAI API(`gpt-4o-mini`)를 활용하여 터미널 환경에서 즐길 수 있는 대화형 스무고개 게임 프로토타입입니다.

## 실행 방법

```bash
python projects/mackery10000-lab/app.py
```

## 게임 모드

1. **AI가 맞히기 (Mode A)**: 사용자가 정답 단어를 정하고, AI가 20개의 질문을 통해 단어를 추리하여 맞힙니다.
2. **사용자가 맞히기 (Mode B)**: AI가 비밀 단어를 선택하고, 사용자가 20번의 질문을 던져 정답을 맞힙니다.

## 난이도 설정

- **하**: 친숙한 단어 / 직접적이고 핵심적인 힌트 및 질문
- **중**: 일반적인 난이도의 단어 및 질문/추론
- **상**: 추론하기 어려운 단어 / 우회적이고 최소한의 힌트
