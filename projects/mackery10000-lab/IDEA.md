# 스무고개 미니게임 AI

## 1. 프로젝트 개요

OpenAI API를 활용하여 AI와 스무고개를 플레이할 수 있는 미니게임을 제작한다.

사용자는 게임 시작 시 두 가지 역할 중 하나를 선택할 수 있다.

1. **AI가 맞히기**  
   사용자가 정답 단어를 정하고, AI가 질문을 통해 정답을 추리한다.

2. **사용자가 맞히기**  
   AI가 비밀 단어를 정하고, 사용자가 질문을 통해 정답을 추리한다.

두 모드 모두 `상 / 중 / 하` 세 단계의 난이도를 제공한다.


## 2. 게임 모드

### Mode A. AI가 맞히기

사용자가 먼저 하나의 단어를 정답으로 지정한다.

AI는 최대 20개의 질문을 하며 사용자의 답변을 바탕으로 정답을 추리한다.

예시:

사용자 정답:
`고양이`

AI:
`살아있는 생물인가요?`

사용자:
`네`

AI:
`주로 사람이 집에서 키우는 동물인가요?`

사용자:
`네`

AI:
`고양이인가요?`

사용자:
`정답`


### Mode B. 사용자가 맞히기

게임 시작 시 AI가 하나의 비밀 단어를 선택한다.

선택된 단어는 사용자에게 공개하지 않는다.

사용자는 최대 20개의 질문을 하며 AI의 답변을 통해 정답을 추리한다.

예시:

AI:
`단어를 정했습니다. 질문을 시작해주세요.`

사용자:
`생물인가요?`

AI:
`네.`

사용자:
`사람이 키울 수 있나요?`

AI:
`네.`

사용자:
`고양이인가요?`

AI:
`정답입니다!`


## 3. 난이도 설정

| 난이도 | AI가 맞히기 | 사용자가 맞히기 |
|---|---|---|
| 하 | 핵심적인 질문을 빠르게 선택하고 높은 추론 능력으로 정답을 맞힌다. | 비교적 친숙하고 쉽게 추론할 수 있는 단어를 선택하며 답변에 충분한 정보를 제공한다. |
| 중 | 일반적인 수준의 질문과 추론을 사용한다. | 적당한 난이도의 단어를 선택하고 일반적인 수준으로 답변한다. |
| 상 | 질문을 조금 더 우회적으로 진행하거나 제한된 정보만 활용하여 추리한다. | 추론하기 어려운 단어를 선택하고 정답을 직접적으로 드러낼 수 있는 표현을 피한다. |

난이도에 관계없이 AI는 거짓 정보를 제공해서는 안 되며, 난이도는 **정답을 숨기는 정도와 추론 난이도**를 조절하는 방식으로 구현한다.


## 4. 기본 게임 규칙

- 한 게임에서 사용할 수 있는 질문은 최대 20개로 제한한다.
- 사용자는 게임 시작 시 역할과 난이도를 선택한다.
- 질문 횟수를 화면에 표시한다.
- AI는 이미 나온 질문과 답변을 기억하여 일관성 있게 추론해야 한다.
- 정답을 맞히면 즉시 게임을 종료한다.
- 20개의 질문을 모두 사용해도 정답을 맞히지 못하면 패배 처리한다.
- 게임 종료 후 다시 플레이하거나 모드를 변경할 수 있도록 한다.


## 5. AI 응답 규칙

### AI가 맞히기 모드

AI는 이전 질문과 답변을 바탕으로 다음 질문을 선택한다.

가능하면 정답 후보를 효과적으로 줄일 수 있는 질문을 우선한다.

정답을 충분히 추론했다고 판단하면 질문 대신 정답을 제시할 수 있다.


### 사용자가 맞히기 모드

AI는 게임 시작 시 하나의 비밀 단어를 정한다.

게임 도중에는 해당 단어를 변경하지 않는다.

사용자의 질문에 대해 정답을 기준으로 일관성 있게 답변한다.

가능한 경우 다음과 같은 짧은 답변을 기본으로 사용한다.

`네 / 아니요 / 경우에 따라 다릅니다 / 관련 없습니다`

사용자가 정답을 직접 말하면 비밀 단어와 비교하여 정답 여부를 판단한다.


## 6. 프로그램 실행 흐름

프로그램 실행

→ 게임 모드 선택

→ 난이도 선택

→ 정답 단어 설정

→ 스무고개 시작

→ 질문 및 답변 반복

→ 정답 판정

→ 게임 결과 출력

→ 재시작 또는 종료


## 7. 목표

단순한 채팅 프로그램이 아니라 AI가 이전 대화 내용을 기억하고 추론하여 스무고개를 진행할 수 있는 프로토타입을 구현하는 것을 목표로 한다.

특히 동일한 게임이라도 사용자의 역할과 난이도 설정에 따라 AI의 질문 방식, 단어 선택, 답변 방식이 달라지도록 구현한다.
