# 삼행시 생성기 (app.py)

사용자가 입력한 세 글자 단어나 이름을 바탕으로 OpenAI API를 활용해 삼행시를 생성하는 CLI 프로그램입니다.

## 실행 방법

1. 프로젝트 최상위의 `.env` 파일에 `OPENAI_API_KEY`가 입력되어 있는지 확인합니다.
2. 아래 명령어로 프로그램을 실행합니다.

```bash
python projects/dpwns103020/app.py
```

## 주요 기능
- **세 글자 입력 검증**: 세 글자가 아닌 단어 입력 시 재입력을 안내합니다.
- **AI 삼행시 생성**: `gpt-4o-mini` 모델을 사용하여 각 글자로 시작하는 운치 있는 문장을 생성합니다.
