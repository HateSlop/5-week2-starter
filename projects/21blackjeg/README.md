# 듣고 맞히는 음감 퀴즈

저장소 최상위에서 실행합니다. 이미 설치된 `openai`, `python-dotenv`와 Python 표준 라이브러리만 사용합니다.

```bash
python projects/21blackjeg/app.py
```

저장소 최상위 `.env`에 `OPENAI_API_KEY`를 설정해 두세요. `OPENAI_MODEL`도 같은 파일에서 읽으며, 비어 있으면 `gpt-4o-mini`를 사용합니다. 실행 위치와 관계없이 이 파일만 읽습니다.

- **하 / 중 / 상**: 각각 서로 다른 1 / 2 / 3개의 음을 1.5초 동안 동시에 재생합니다.
- **시작**: 난이도를 고르면 `도 레 미 파 솔 라 시 도`를 한 음당 0.55초, 음 사이 무음 0.04초로 이어서 들려줍니다. 음계는 한 파일로 재생하며, 계이름은 재생 일정에 맞춰 하나씩 표시합니다(출력 장치의 시작 지연에 따라 약간 차이가 날 수 있습니다). 마지막 도는 첫 도보다 높은 음입니다. 이어서 `이 소리가 "도"입니다.`라는 안내와 함께 처음의 도를 2초 동안 다시 들려준 뒤 문제를 냅니다. 문제를 푼 뒤 음계를 다시 들을 때도 동일하게 재생합니다.
- **출제 범위**: 도~시의 12음으로, 반음을 포함합니다.
- **답 입력**: `도`, `C#`, `도 미 솔`, `C,E,G`처럼 입력하세요. 여러 음의 순서는 무관합니다. `도#=레b`, `레#=미b`, `파#=솔b`, `솔#=라b`, `라#=시b`처럼 같은 높이의 음은 모두 정답으로 인정합니다. 영어 음이름과 `♯`, `♭`, `샵`, `플랫` 표기도 사용할 수 있습니다.
- **조작**: 답을 입력할 때 `다시` 또는 `r`로 문제 소리를 다시 듣습니다. `난이도`로 변경하면 음계를 먼저 들려줍니다. `q` 또는 `종료`로 끝냅니다.
- **문제를 푼 뒤**: Enter로 다음 문제를 시작하거나, `음계` 또는 `s`로 도레미파솔라시도를 다시 들을 수 있습니다. 음계 재생 후에는 같은 선택 메뉴로 돌아옵니다.
- **출력**: 내 답은 입력한 표현과 순서 그대로 표시하고, 정답은 `라#(시b)`처럼 같은 음의 두 표현을 함께 표시합니다. 여러 음은 `·`로 구분합니다. 예를 들어 정답이 `라`일 때 `시b`를 입력하면 서로 다른 음이므로 오답입니다. 맞힌 음의 수와 누적 기록도 표시하며 AI 코칭 문장은 표시하지 않습니다.
- **OpenAI 사용**: 난이도 선택 또는 다음 문제 선택 시, 무작위로 구성한 후보 중 출제할 음 조합을 OpenAI가 고릅니다. API 결과를 검증한 뒤 소리로 재생하고 채점 후 정답으로 표시합니다. 출제당 요청 1회, 최대 200토큰이며 자동 재시도는 없습니다. 답 제출과 소리·음계 재생에는 API 요청이 없습니다. 출제 실패 시 다음 선택을 기다립니다.

macOS의 `afplay`, Windows의 기본 소리 재생 기능을 사용합니다. Linux는 기존에 `aplay` 또는 `paplay`가 있어야 합니다. 볼륨과 출력 장치를 확인해 주세요. 소리는 표준 라이브러리로 합성하고 임시 WAV 파일은 재생 후 삭제합니다. 기록은 실행 중에만 유지됩니다.

검사 명령:

```bash
python tools/check_submission.py 21blackjeg
```
