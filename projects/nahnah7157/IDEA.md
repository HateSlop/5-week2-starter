# APA 7 참고문헌 교정기

여러 참고문헌을 한 번에 받아 APA 7판 형식으로 교정하는 터미널 도구입니다. 기존처럼 자유 텍스트만 요청하지 않고, 모델 응답을 **입력 순서가 고정된 JSON 배열**로 받습니다. 따라서 항목 누락·병합을 감지할 수 있고, 정보가 부족한 항목은 억지로 채우지 않고 `검토 필요`로 표시합니다.

## 설치

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```


## 실행

```bash
python apa_corrector.py references.txt
python apa_corrector.py references.txt --markdown --output apa_result.md
```


## 여러 건 붙여 넣기 규칙

정확도를 위해 참고문헌 하나당 빈 줄을 하나 넣는 방식을 권장. 다음 형식도 인식.

- `1. 참고문헌`, `2) 참고문헌` 같은 번호 목록
- `- 참고문헌`, `• 참고문헌` 같은 불릿 목록
- 충분히 긴 참고문헌이 한 줄에 하나씩 놓인 목록

한 참고문헌이 여러 줄로 줄바꿈되었고 항목 사이에 빈 줄이 없다면 하나의 항목으로 보존합니다. 이 경우 항목 사이에 빈 줄을 넣는 편이 안전합니다.

## 교정 원칙

- 원래 입력 순서를 보존합니다. 최종 논문에 붙이기 전, 필요하면 저자 성 기준 알파벳순 정렬을 하세요.
- 서지정보를 추측해 만들지 않습니다. 저자·발행연도·출판사·DOI 등이 빠져 있으면 가능한 형식까지만 교정하고 경고합니다.
- DOI는 `https://doi.org/...`로 유지하고, 입력에 없는 URL·DOI는 추가하지 않습니다.
- APA 형식의 정확성은 입력 서지정보의 완전성에 의존하므로 `⚠ 검토 필요` 항목은 원문 또는 출판사 페이지와 대조하세요.
